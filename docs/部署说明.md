# 部署与配置

当前版本使用 V1–V7 完整迁移。V1–V6 创建结构、索引、视图、过程/触发器和两阶段演示种子数据，V7 增加库存流水前后数量平衡 CHECK；完整安装包含 28 张应用表、7 个视图、4 个过程、18 个触发器。这套重建基线适用于空库安装，不是给旧开发链继续追加的升级脚本。不要让旧版后端连接已经重建的数据库，也不要让新版后端直接连接保留旧 Flyway 历史的数据库。

## 环境

- Windows 10/11 或 Linux
- JDK 17
- MySQL 8.0
- Node 22 仅用于前端构建
- Maven 3.9.11；Windows 使用项目的 `mvnw.cmd` 获取，首次需要 curl 和网络。以下命令以 PowerShell 为例；Linux 需安装 Maven 3.9.11，并将 `.\mvnw.cmd` 替换为 `mvn`

## 后端

生产运行前必须设置数据库、JWT 和初始账号环境变量。执行：

```powershell
cd backend
.\mvnw.cmd -v
.\mvnw.cmd package
java -jar target\hospital-inpatient-1.0.0.jar
```

后端启动时自动验证并迁移数据库。不要在共享数据库中启用 Flyway clean。

如果 MySQL 开启了二进制日志，首次迁移需要由管理员临时执行：

```sql
SET GLOBAL log_bin_trust_function_creators = 1;
SHOW VARIABLES LIKE 'log_bin_trust_function_creators';
```

确认值为 `ON` 后再启动后端。该全局值在 MySQL 重启后恢复默认；当前 18 个触发器创建完成后，系统日常运行不依赖此开关。不要为了创建触发器给应用账号授予 `SUPER`。

住院等业务编号使用带服务器唯一性的 `UUID_SHORT()`；医嘱号使用创建日期加至少 8 位数据库 ID，费用号由应用生成。三类编号均有唯一约束兜底。

## 前端

```powershell
cd frontend
npm.cmd ci
npm.cmd run build
```

将 `dist/` 交给 Nginx 或同类静态服务器，并把 `/api` 反向代理到 `http://127.0.0.1:8080`。生产环境将 `HOSPITAL_FRONTEND_ORIGIN` 设置为实际前端域名。

## 运行检查

- `/actuator/health` 返回 UP。
- 登录、权限菜单和一个受限接口正常。
- Flyway schema history 无失败记录。
- 数据库连接池、磁盘、MySQL 慢查询和应用错误日志无异常。

## 从旧迁移链切换到 V1–V7

旧 V6/V8/V13 环境不能原地追加本基线。切换前必须安排停机窗口，并完成可恢复的逻辑备份；当前源码目录不附带旧数据库备份，备份文件应保存到项目目录之外，并记录时间和校验值。

1. 停止旧应用写入，记录当前 Flyway 版本、表数量及关键账目汇总，导出完整数据库并校验备份可读。
2. 新建目标数据库，或在确认备份可恢复后重建原目标库。不要在未验证备份时删除旧库。
3. 如 MySQL 开启 binary log，由管理员开启 `log_bin_trust_function_creators=1`；不要给应用账号授予 `SUPER`。
4. 使用新版后端在空库运行 V1–V7。首次启动必须提供 `HOSPITAL_BOOTSTRAP_ADMIN_PASSWORD`，否则零用户数据库不会自动产生可登录账号。
5. 执行 `database/verify.sql`，检查对象数量、演示数据规模和 V7 库存平衡约束；再运行完整后端测试、前端构建和页面冒烟。
6. 如需保留旧业务数据，必须使用单独设计并经过对账的数据迁移脚本导入。旧兼容字段、旧执行过程和 `LEGACY` 阶段不能直接搬入新结构。

Flyway 校验失败通常表示目标库不是空库或文件与已执行版本不一致。应先核对连接目标和迁移记录；不要盲目修改 checksum、删除 `flyway_schema_history` 或运行 `repair`。当前源码不附带针对旧本机测试库的临时修复工具。

## 时间与运行配置

连接池统一执行 `SET time_zone='+00:00'`，JDBC 时间解释和数据库函数均使用 UTC；前端显示浏览器本地时间，统计日期按 UTC 自然日。历史时间若曾使用混合时区，需人工核对来源。

前端访问地址应与 `HOSPITAL_FRONTEND_ORIGIN` 一致，默认是 `http://localhost:5173`；`localhost` 与 `127.0.0.1` 属于不同 Origin。后端默认端口为 8080，开发代理可通过 `HOSPITAL_API_PROXY` 指定。

如特定 JDK 出现本地 socket 临时目录错误，可显式指定一个已经存在且可写的临时目录；不要依赖已清理的项目过程目录。业务库和测试库必须分别配置；两套版本的迁移链不同，不应共用业务库或测试库。
